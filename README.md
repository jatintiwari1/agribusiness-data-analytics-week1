# Agribusiness Data Analytics – Week 1

## Project Overview

This project simulates the initial phase of a data analytics project in agribusiness.

The project focuses on:

- Agricultural dataset selection
- Data acquisition
- SQL data import
- Data quality profiling
- Data cleaning
- Data validation
- Preliminary transformation

## Dataset

The selected dataset is FAOSTAT agricultural crop-production data published by the Food and Agriculture Organization of the United Nations (FAO).

The dataset contains agricultural statistics such as:

- Area harvested
- Production quantity
- Yield
- Country/area
- Commodity/item
- Year
- Measurement unit

## Dataset Source

FAOSTAT:

https://www.fao.org/faostat/en/

FAO Crop Production Dataset:
